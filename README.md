# Разбор скипов

Публичные страницы с отдельными покадровыми разборами двух участников. Публикация разрешена пользователем 4 октября 2026 года.

- [Общий вход](https://ramchike.github.io/athletics-reviews/)
- [Участник в красном](https://ramchike.github.io/athletics-reviews/red/)
- [Светловолосый участник](https://ramchike.github.io/athletics-reviews/white/)

Исходная закрытая база тренировок сюда не копируется. Полные оригинальные видео отсутствуют; страницы содержат выбранные кадры и короткие демонстрационные фрагменты. Источник демонстраций: Noah Lyles, «How To Get FASTER with DRILLS», https://www.youtube.com/watch?v=xiYTMBLqp8c.

Статический сайт: GitHub Pages, ветка main, корень, без сборки Jekyll. У страниц явно указан UTF-8. Предположительные совпадения фаз не объявлены подтверждённым совпадением анатомических сторон.
