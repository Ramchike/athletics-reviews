## Минимальная следующая проверка

Внутри назначенных повторов снять каждому два 3-point на настоящие 10 м: без новой команды и с одной командой. Полное тело и первые пять контактов сбоку, свободная дорожка, сумка вне фона стоп. Указать дату, исходную частоту и замедление. Мишу снять в двух назначенных Falling, обозначив намерение ускоряться, а не объяснять движение шагом.

На следующем занятии повторить без напоминания. Для результата по времени нужны одинаковые дистанция, обувь, старт и начало отсчёта; предпочтительно электронные ворота. Это завершит проверку ближайшей гипотезы, но не всей техники 100 м. Новые попытки ради видео не добавлять поверх плана.

Технические проверки процедуры — [отдельно](start-tool-checks.md). Позднейший запрос добавил открытое размещение на GitHub и визуальную пару к каждому основному совету. Пользователь явно разрешил публичный доступ («В паблик все лей»). Подготовлены [карточки для телефона](../reviews/2026-10-04-starts-phone.md), выбранные собственные производные в `reviews/assets/`, HTML-версии материалов и [вход GitHub Pages](https://ramchike.github.io/athletics-reviews/). Оригиналы и служебные manifest остаются местными.

## Полная двухчасовая программа: позднейшее уточнение 5 октября

Порядок A/B/C → оба Fast Legs → стартовый блок уточнён пользователем. Сначала отдельные записи спортсменов; затем добавлены девять временных окон на 120 минут, 14 карточек с действиями/ролью/проверкой, авторскими видео и доступными личными короткими MP4. Основные быстрые метры не увеличены; СБУ и Fast Legs посчитаны отдельно. Push-Up только заменяет один назначенный 3-point. Собственная B/C/Fast-серия и полноценный Falling Миши пока не опознаны, на сайте отсутствующий материал обозначен.
