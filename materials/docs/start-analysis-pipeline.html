Порядок анализа стартов без колодок

Версия 1, 4 октября 2026 года. Текущий разбор, источники, проверка готовых навыков.

Вход и сохранение

Принимать указанную папку, уточнить людей, дату занятия и замедление. Уже известно: Рамир в красном, Миша с белыми волосами. Не брать дату загрузки за дату тренировки. Оригиналы не изменять. Оригиналы и служебные сетевые manifest остаются в исключённой из Git media/. Позднейшее разрешение пользователя 4 октября распространяется на публичные отчёты и выбранные собственные производные в существующем athletics-reviews: хранить их в reviews/assets/ и публиковать без повторного вопроса о том же способе доступа. Оно не разрешает распространять чужие оригиналы.

Предпочтительный способ — выбранные кадры через ограниченные HTTP Range, без сохранения целого ролика. При этом байты видео всё равно передаются и декодируются: это не просмотр «без скачивания вообще». Скрипт stream_frames.py отказывается читать полный ответ, если сервер не соблюдает Range. При отказе сервера не переходить молча на полную загрузку. Manifest хранит источник, размер, PTS, поворот, хеш выбранного кадра и сетевой объём; хеш исходного ролика неизвестен, если он целиком не прочитан.

Два прохода

  1. Обзор: найти упражнения, отдельные попытки, пригодные ракурсы и перекрытия. Редкие обзорные кадры не позволяют нумеровать первые шаги.
  2. Непрерывный короткий участок каждой выбранной попытки: исходная поза → начало движения → первый контакт → отрыв → следующие контакты. При необходимости уплотнить выборку до соседних кадров исходника. Даже 10 кадров на секунду файла может пропустить контакт при реальной скорости; этот темп не является достаточным по умолчанию.

Для Wall drill различать удержание, медленный подъём, быструю одиночную смену с фиксацией и серию быстрых смен. Не судить удержание по переходному кадру. Для Reaction Start нужны доступный сигнал и последовательность движения; обычный старт не доказывает реакцию по случайному звуку.

Разметка и углы

Ручные точки проверять на исходном разрешении. Связать каждый кадр с участником, ногой, фазой и файлом. Не отражать картинку для сравнения, не менять сторону ноги. При перекрытии сустава оставить угол неизвестным. Разметка средствами геометрии/Pillow сохраняет реальные пиксели; генеративные изображения для измерений не подходят.

Для каждого угла указывать точки и определение: плечо–таз к горизонтали изображения; таз–колено–голеностоп — внутренний угол колена; плечо–таз–колено — геометрический угол бедра к корпусу, который не равен клинической оценке тазобедренного сгибания. Опорная стопа на носке не означает, что голеностоп и точка контакта совпадают. Линия плечо–голеностоп проверяет общий силуэт, а не положение всех позвонков.

Округлять пользовательские оценки до целых градусов и отмечать неопределённость. Смещение выбранных точек на несколько пикселей показывает чувствительность расчёта, но не исправляет перспективу и не является доверительным интервалом. При косом ракурсе цифры остаются углами проекции. Горизонталь изображения не гарантирует горизонталь дорожки; отдельный кадр не измеряет прогиб поясницы, направление силы или истинный центр массы.

Вывод и перенос

Наблюдение → возможное влияние → одна пробная команда → повторная попытка → проверка настоящего ускорения. Сначала механика, затем длина шагов. Сантиметры требуют масштаба в плоскости бега; время и частота — известной временной шкалы. Таз можно использовать как ориентир перемещения, но не называть истинным центром массы.

Проверка переноса: 2–3 сопоставимые попытки без команды, затем с одной командой, затем без неё на следующем занятии. Сохранять все попытки, условия, ошибку хронометража и восстановление. Для 5/10/20/30 м нужны фиксированные дистанции, одинаковое начало отсчёта и предпочтительно электронные ворота; ручное время не позволяет уверенно судить о малых улучшениях. Не превращать один удачный повтор в доказательство эффективности.

Итог оформлять по 14 разделам, отдельно для людей. Если контакты не видны, прямо отметить границу разбора и дать способ переснять. После появления колодок провести отдельную проверку: старт без педалей не воспроизводит всю их механику.
