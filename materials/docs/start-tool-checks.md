# Проверки инструментов разбора стартов

Проверено 4 октября 2026 года. Проверка программы не равна доказательству правильности анатомических точек или спортивного вывода.

## Что проверено

- Все восемь SKILL.md в проекте проходят установленный `skill-creator/scripts/quick_validate.py`. Два готовых навыка сохраняют происхождение и лицензии; у scientific-critical-thinking поле compatibility перенесено из YAML в текст, исходник оставлен рядом. Валидатор проверяет структуру, не компетентность тренера.
- Десять тестов `tests.test_start_geometry` и `tests.test_video_analysis` прошли в окружении Python 3.12 с PyAV, NumPy и Pillow. Проверены углы векторов, невозможность угла по совпадающим точкам, стороны в экспериментальном сопоставлении, ограниченное чтение HTTP Range и отказ принимать полный ответ вместо Range.
- Независимая проверка выборки: тестовый ролик полностью декодируется в эталонную последовательность, затем сравниваются пиксели и PTS выбранных кадров после последовательных запросов, повторной метки, обратного поиска и большого промежутка. Этот тест ловит ошибку повторного использования декодера, а не только повторяет реализацию.
- Понятные метки времени проверены на переносе к следующей минуте: вместо сырых секунд используется формат `1:25,0`. Это по-прежнему положение в файле, не физическое время при неизвестном замедлении.
- Ручные аннотации сохраняют координаты исходных пикселей и SHA-256 исходного/полученного кадра. Изображения не отражаются; скрытые голени друга в опорах 3–5 исключены из численной разметки. Прежние пробные варианты с непригодными точками не используются в итоговом отчёте.
- Для Wall проведён расчёт чувствительности при сдвиге точек на ±3 пикселя. Он не включает перспективу, погрешность от одежды и выбор фазы; его нельзя называть доверительным интервалом.

Основные инструменты: [stream_frames.py](../scripts/stream_frames.py), [annotate_start_frame.py](../scripts/annotate_start_frame.py), [проверки](../tests/test_start_geometry.py). Для этого ручного разбора не требуется запускать MediaPipe или скачивать модели.

## Чего эти проверки не доказывают

Точность 3D-углов, истинный центр массы, направление силы, торможение, мышечную активацию и улучшение скорости не проверены. Точки на одежде — приближение. Наиболее надёжные выводы здесь качественные: линия у стены, прямой или промежуточный способ смены, заметное изменение положения туловища в одной последовательности.

Оригинальные ролики целиком не сохранены; байты для декодирования всё равно получены по сети. Ограничение восьми блоков по 1 МиБ относится к кешу RangeReader, а не ко всей памяти процесса: декодер и изображения используют дополнительную память. Полный хеш каждого исходного видео неизвестен. Совпадение имени и размера — кандидат на дубль, не подтверждение.

Исходные разметки лежат в исключённой из Git `media/start-review-2026-10-04/`. По последующему разрешению открытого доступа выбранные собственные производные скопированы в `reviews/assets/starts-2026-10-04/`, ссылки текущих отчётов переведены на них. Координаты и хеши выбранных аннотаций сохранены в [measurements.json](../reviews/assets/starts-2026-10-04/measurements.json), происхождение копий/кропов/анимаций — в [provenance.json](../reviews/assets/starts-2026-10-04/provenance.json). Служебные сетевые manifest в публикацию не включены. Подтверждения переноса в ускорение ещё нужны по [плану проверки](start-task-status.md).

Версию для телефона готовит [build_mobile_start_review.py](../scripts/build_mobile_start_review.py); зависимости — [requirements-review-site.txt](../requirements-review-site.txt). Схемы SVG являются отдельными условными рисунками, не измеренной анатомией и не изображением будущего результата. Прежние полные тексты отчётов остаются рядом.

## Проверка чтения с телефона

Перед отправкой проверены Chromium на ширинах 360 и 390 px и на компьютере 1280 px: карточки, отдельный выбор участника, раскрытие GIF и загрузка изображений. У карточек, полного отчёта и плана нет горизонтального переполнения страницы; широкие таблицы прокручиваются внутри. Все 509 местных адресов в 75 новых HTML-страницах разрешаются в файлы. Общая проверка Python-инструментов: 17 тестов прошли; FFmpeg/ffprobe подключены из местного кеша. Служебные скриншоты проверки остаются в media/publishing-checks/.
