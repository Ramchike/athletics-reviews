# Публикация и корневые навыки

5 октября 2026. Сайт athletics-reviews — удобный доступ к спортивной базе; исходные записи хранятся также в athletics-lab. В обоих корневые AGENTS.md, .agents/skills/, docs/, reviews/, plans/ сохраняют смысл путей. materials/ в публичной версии поддерживает старые адреса и не является рабочим входом.

## Полный экспорт из athletics-lab

Проверить удалённые изменения публичного репозитория перед экспортом. Если в публичной базе исправлены спортивные записи или навыки, сначала согласовать их с базой athletics-lab; не перезаписывать молча.

```sh
python scripts/build_react_review_site.py --public-root /path/to/athletics-reviews-checkout
```

Процедура сохраняет обычные отчёты, выбранные собственные изображения, копирует рабочие документы и навыки в корень, строит React-сайт и входы страниц. Файлы навыков в materials переименованы в ARCHIVED-SKILL.md, HTML совместим со старыми ссылками. Прямые страницы /starts/, /skills/, /map/, /research/, /learning/, /tasks/, /plan/ имеют index.html и открываются после обновления на GitHub Pages.

## Работа из корня athletics-reviews

```sh
npm --prefix website ci
npm --prefix website run build
node website/scripts/publish-build.mjs
```

prebuild читает текущие корневые карточки, документы и восемь SKILL.md; первоначальные видео не нужны. Процедура не удаляет кадры и документы. После сборки проверить интерфейс, затем отправить согласованную публикацию в GitHub и проверить построенный commit Pages и реальные URL.

## Критерии проверки

В каждом упражнении при выборе Рамира или Миши только его оценки и реальные личные кадры; отсутствующий кадр обозначен. Смена сохраняется в URL, копирование ссылки, обновление и «Назад» не теряют её. Проверять поиск, фильтр упражнений, раскрытие объяснений, показ GIF, каталог 2 готовых / 6 местных навыков, корневые пути, сохранность лицензий и пикселей старой разметки, экраны 360/390 px, загрузку и reduced-motion.

Сеточная иллюстрация на главной — собственный условный SVG-эскиз, не модель измеренного движения. Присланные картинки служат оформительскими референсами и не переиздаются. Цвет и анимация не являются доказательством правильности техники.

## Полная программа, 5 октября

`plans/two-hour-session.json` — данные девяти временных окон (120 минут), четырнадцати карточек, двух индивидуальных вариантов и карты следующих задач. `plans/next-start-session.md` сохраняет развёрнутое объяснение и ограничения. При изменении сверять оба документа.

`/plan/` открывает всю программу, `/exercises/?athlete=ramir&exercise=wall-march` — конкретную карточку. Выбор участника и упражнения хранится в URL. Чужие демонстрации встроены с авторской ссылкой; оригиналы не копируются. Девять собственных MP4 — повтор выбранных кадров, не реальные измерения времени. Их сборка: `scripts/build_program_clips.py --ffmpeg <путь>`, только при доступных исходных кадрах в исключённой `media/`. Сайт и публичная сборка используют уже выбранные производные; исходники им не нужны.

Проверка полной программы: `scripts/check_programme.py --base-url <URL> --chromium <путь>`. Проверяет 360/390/1280 px, четырнадцать карточек, собственные плееры, персональные переключатели, URL/возврат, объяснения и отсутствие горизонтальной прокрутки. Общие проверки прежних разборов — `scripts/check_react_review.py`. Встроенный YouTube может зависеть от сети и региона; авторская ссылка остаётся доступной.

Проверка 5 октября: сборка из каждого репозитория успешна; обе браузерные проверки прошли на 360, 390 и 1280 px, включая девять воспроизводимых собственных фрагментов, четырнадцать карточек, девять разделов, reduced-motion и ошибку загрузки кадра. Проверено содержимое выбранных обрезок. T3 preview явно недоступен в этой среде; использован резервный Playwright. Встроенное воспроизведение чужого YouTube не подтверждено — доступна авторская ссылка.
