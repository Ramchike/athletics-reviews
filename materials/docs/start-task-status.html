Минимальная следующая проверка

Внутри назначенных повторов снять каждому два 3-point на настоящие 10 м: без новой команды и с одной командой. Полное тело и первые пять контактов сбоку, свободная дорожка, сумка вне фона стоп. Указать дату, исходную частоту и замедление. Миши снять в двух назначенных Falling, обозначив намерение ускоряться, а не объяснять движение шагом.

На следующем занятии повторить без напоминания. Для результата по времени нужны одинаковые дистанция, обувь, старт и начало отсчёта; предпочтительно электронные ворота. Это завершит проверку ближайшей гипотезы, но не всей техники 100 м. Новые попытки ради видео не добавлять поверх плана.

Технические проверки процедуры — отдельно. Позднейший запрос добавил открытое размещение на GitHub и визуальную пару к каждому основному совету. Пользователь явно разрешил публичный доступ («В паблик все лей»). Подготовлены карточки для телефона, выбранные собственные производные в reviews/assets/, HTML-версии материалов и вход GitHub Pages.
