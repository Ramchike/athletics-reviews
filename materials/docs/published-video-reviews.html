Прежние закрытые страницы Sites

Дата публикации: 4 октября 2026 года. Обе версии успешно опубликованы, статус подтверждён сервисом Sites. Доступ закрытый, для аккаунта владельца; публичный GitHub Pages не создавался и аудитория GitHub-репозитория не менялась.

  • Участник в красном: страница, ручной пересмотр.
  • Светловолосый участник в белом поло: отдельная страница, отдельный разбор.

Использован навык Sites hosting. Чужие существующие сайты и их домены не изменялись. Каждая страница содержит только свои тренировочные фрагменты и учебные демонстрации. Личные оригиналы целиком не загружались; переданы выбранные кадры. Проверены UTF-8, отдельные наборы участников, кнопки соседних кадров, переключатели демонстраций, разметка и отсутствие горизонтального переполнения на ширине 390 px.

Исходники опубликованных страниц сохранены в исключённых из основного Git media/hosting/red и media/hosting/white и в отдельных приватных репозиториях Sites. Для обновления использовать их существующие .openai/hosting.json с теми же project_id, не создавать новые сайты. Ключей и токенов в файлах нет.

Старое сопоставление разных ног отозвано. Ни одна новая пара не названа подтверждённым совпадением анатомической ноги и руки. Просмотрщик сохраняет все извлечённые кадры выбранных последовательностей, но не каждый кадр оригинального видео.
