# Створ на телефоне

**Цель** — пройти от первого открытия до видео конкретной попытки. На первом телефоне создать старт, на втором подключить финиш, провести замер, затем найти запись через спортсмена.

Один референс — экран Activity из Nike Training Club. В Створ перенесены иерархия истории тренировок, переход по нажатию на всю строку и нижняя навигация с подписью. Цвета, иконки, онбординг и компоненты отрисованы для Створа. [Nike Training Club · Activity на Mobbin](https://mobbin.com/screens/d921995e-5680-4b3a-995e-187fea253728)

## Путь и состояния

| Экран | Действие | Что дальше |
| --- | --- | --- |
| Первый вход | Пройти три коротких экрана или пропустить | «Замер». Инструкцию можно повторно открыть через «?». |
| Замер | «Создать старт» | QR, код и кнопка копирования ссылки. Настройки попытки открываются после подключения. |
| Замер | «Подключить финиш» | Сканер. Если камера недоступна, остаётся вход по коду. |
| Финиш | Выставить линию и нажать «Финиш готов» | На старте можно запускать попытку. |
| Спортсмены | Нажать «+» и ввести имя | Открывается «Имя / Результаты». Повтор имени подсвечивает ошибку у поля. |
| Результаты | Выбрать дистанцию и порядок | «Лучшие» и «Худшие» сравнивают попытки внутри дистанции. |
| Карточка попытки | Нажать любую строку результата | Видны время, дата, дистанция, режим старта, видео этого телефона и кадры с линии, если они записаны. |

## Компоненты и проверка

| Компонент | Проверка |
| --- | --- |
| Кнопки | Основные области нажатия от 44 × 44 CSS px. При нажатии меняются масштаб и яркость. При включённом Reduce Motion переходы отключены. [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/buttons) |
| Нижняя навигация | Два корневых раздела с иконками, подписями и выделением текущего. Отступ учитывает нижнюю безопасную зону. [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/tab-bars) |
| Поля | Системные элементы, шрифт 16 px, подпись остаётся над полем. У ввода мягкий внутренний фокус, у кнопок сохраняется видимый клавиатурный фокус. [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/text-fields) |
| Контраст | Основной текст на фоне 15,96:1, вторичный 6,86:1, плейсхолдер в поле 5,38:1. [WCAG 2.2, Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum) |

`verify-mobile.mjs` проверяет подключение двух браузерных клиентов через QR, ручной вход, разрешение камеры, добавление спортсмена, сортировку и воспроизведение после перезагрузки. Скриншоты снимаются на ширинах 320, 390 и 430 CSS px. Запуск требует Playwright с Chromium и Y4M, где бегун пересекает линию справа налево. В `STVOR_PLAYWRIGHT` можно указать путь к уже установленному модулю Playwright, в `STVOR_CHROME` — путь к Chromium. Без `STVOR_URL` скрипт поднимает таймер на локальном случайном порту.

```bash
heavy-build --memory 2G -- env STVOR_CAMERA=/path/to/pass.y4m STVOR_SCREENSHOTS=/path/to/screenshots node sprint-timer/verify-mobile.mjs
```
