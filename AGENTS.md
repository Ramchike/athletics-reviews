# Спринт 60/100 м — Рамир и Миша

Тренировочный проект двух новичков: техника, план, журнал, разборы видео, сайт.

- Тренировочные вопросы, план, запись занятия → скилл `sprint-coach` (`.agents/skills/sprint-coach/SKILL.md`).
- Видео (Google Drive, YouTube) → скилл `sprint-video-review`.
- Исследование, источники, «пересерчи» → скилл `sprint-research`.

Главное:
- Говори просто, по имени (Рамир — красный, Миша — белые волосы), с ясным вердиктом 🟢/🔴/⚪ и одной главной подсказкой. Что раздражало раньше — `docs/feedback.md`.
- Критерии техники и порядок самых дорогих ошибок — `docs/technique.md`. Маршрут прогресса — `docs/roadmap.md`.
- Видео не скачивать целиком: `scripts/drive.py` + `scripts/stream_frames.py` читают нужные кадры по HTTP Range в `media/` (не в git).
- Репозиторий публичный по решению пользователя. Сайт собирается из `website/` через GitHub Actions при push в `main`: https://ramchike.github.io/athletics-reviews/
- Боль или травма → без быстрого бега, совет к врачу.
